# Note bodies say why and how to apply

## Summary

Claude Code asks for **Why:** and **How to apply:** lines in feedback
and project memories. ilar's notes have a title and summary rule but no
body shape, so a recalled note often says what without when it matters.

## Requirements

- The memory prompt asks for the two lines on decision, preference and
  solution notes.

## Acceptance Criteria

- Prompt test; a few live notes written with it look right.
